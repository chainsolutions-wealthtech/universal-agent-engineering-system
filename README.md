# Universal Agent Engineering System (UAES)

Independent, provider-neutral governed multi-agent engineering platform.

**Distinct new project.** It is neither a fork nor a replacement of `chainsolutions-wealthtech/universal-agent-platform`, `Patricked-code/MCP` or `chainsolutions-wealthtech/Governed-Repository-Template`.

## Mission

Build durable planning, agent identity resolution, canonical memory, governance, coordination, resumable execution and verified software delivery without requiring Codex or Copilot.

## Bootstrap status

Repository created; documentation and architecture proposal will be introduced through a reviewable pull request. **No production runtime, GitHub App authority, external mandate, or live agent identity is established here.**

## Security

No credentials, private conversations or other projects' canonical data may be copied into this public repository. Integrations require explicit verified permissions and isolated governance.
